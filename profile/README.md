## What we build

We build production-grade infrastructure that lets teams and businesses run on technology they fully own.

| Product | What it is | Repo / domain |
| ------- | ---------- | ------------- |
| **LIQAA** | Open-source video conferencing API + self-hostable meeting platform | [liqaa.io](https://liqaa.io) · [@liqaa-cloud](https://github.com/liqaa-cloud) |
| **MyStoq** | E-commerce platform for MENA — multi-tenant, currency-flexible, RTL-first | [mystoq.com](https://mystoq.com) |

## Why open

Half our work ships under AGPL or MIT. The other half is closed because it has paying customers we cannot disturb. We do not pretend the open half exists for charity — it exists because trust compounds when developers can read the source, and trust is the cheapest moat we can build.
